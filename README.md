# Budget Tracker

This project is a simple budget tracking webpage that lets users add expense details and review a list of recent expenses.

## What is included

- A heading and logo image for the tracker
- An add expense form with labeled fields and a category dropdown
- An expense table showing sample data in a structured layout
- A collapsible help section using `<details>` and `<summary>`
- A YouTube budgeting video embedded with an `<iframe>`
- CSS styling with responsive layout and advanced selectors

## Main files

- `index.html` — page structure and content
- `style.css` — styling, layout, and advanced CSS selector rules

## Features used

- Proper table structure using `table`, `thead`, `tbody`, `tr`, `th`, and `td`
- Form elements wrapped in a `form` element with matching IDs
- Dropdown with 5 category options: Food, Transport, Rent, Entertainment, and Other
- Button with `type="button"`
- Image and video media elements
- CSS selectors including descendant selectors, `:nth-child`, `:focus`, and hover states
